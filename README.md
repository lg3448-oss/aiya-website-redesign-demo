# AIYA Full-Screen Website Demo

Presentation-ready, framework-free redesign based on AIYA's existing website and the supplied website strategy. No installation or build step is required.

## Preview

Open `index.html` in Chrome, Edge, or another modern browser. Use the mouse wheel, trackpad, navigation links, or the scene dots on the right.

The desktop experience contains ten full-viewport scenes:

1. Hero
2. Technology Capabilities
3. Featured Online Ordering
4. Products
5. Services
6. API & Payment Ecosystem
7. Why AIYA
8. Results
9. Company
10. Contact

Products and Services are interactive selectors. The Hero contains three rotating messages. Mobile keeps the Hero full-screen and lets content-heavy scenes grow naturally.
