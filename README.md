# AIYA Website Redesign Demo

A modern and responsive website redesign prototype for AIYA Technology System.

This project explores a cleaner, more technology-driven visual direction for the AIYA corporate website, with a focus on AI software, API integrations, payment technology, Clover POS integration, online ordering, automation, and enterprise software solutions.

## Project Status

This repository is a visual design prototype and internal demo.

It is not the final production website.

Some text, product information, company statistics, client logos, and case-study content may be used only for demonstration purposes and may require approval before public release.

## Project Goals

The redesign aims to:

- Create a modern and professional technology-focused website
- Improve messaging clarity
- Simplify website navigation
- Present products and services more clearly
- Improve the desktop and mobile experience
- Create a full-screen presentation-style browsing experience
- Maintain a consistent AIYA brand identity
- Highlight AI, APIs, payments, automation, and enterprise software
- Showcase the AIYA Online Ordering Platform
- Demonstrate Clover POS and Clover Mini integration
- Add a seamless infinite partner logo marquee

## Key Features

- Full-screen homepage sections
- Responsive desktop and mobile layouts
- Continuous AIYA-branded background design
- Modern orange, amber, black, and neutral color palette
- Horizontal hero messaging
- Simplified and bold navigation
- AI and software solution showcase
- API and payment ecosystem presentation
- Clover-integrated online ordering product section
- Infinite horizontal partner logo marquee
- Scroll-snap section transitions
- Product and service showcase

## Partner Logo Marquee

The homepage includes an infinite horizontal partner logo marquee inspired by modern enterprise technology websites.

The marquee includes:

- Continuous right-to-left scrolling
- Seamless looping
- Balanced logo spacing
- Edge fade effects
- Hover pause
- Responsive sizing
- Reduced-motion support

Only approved partner and client logos should be used in the final public version.
